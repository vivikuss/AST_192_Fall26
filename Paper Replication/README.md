## Regenerating data/processed

Everything in `data/processed/` except the small `*.csv` summaries is a cache and
is gitignored. Delete it and re-run the notebooks in order (from the project root,
in `ast192`):

```
jupyter nbconvert --to notebook --execute --inplace notebooks/stage0_validation.ipynb
jupyter nbconvert --to notebook --execute --inplace notebooks/stage1_reproduce_mw14.ipynb
```

Stage 1 rebuilds `fcosi_table.npz` (~1.5 min on 8 cores) and
`fcosi_table_fine.npz` (~3 min), then the per-star posteriors and samples. All
random seeds are fixed in the notebooks, so the outputs are reproduced exactly.
Notebooks are generated by `scripts/build_stage*_notebook.py`; edit those, not
the .ipynb files.

Environment: `conda activate ast192` (pytest is not in it, hence `tests/run_tests.py`).
