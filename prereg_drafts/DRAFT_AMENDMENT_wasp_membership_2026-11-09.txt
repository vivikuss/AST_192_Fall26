1. What went wrong.
   - Section A defines the WASP hosts as the Phase 1 primary sample (297) "restricted to hosts whose hot
     Jupiter has a WASP facility in the NASA Exoplanet Archive disc_facility". It gives 98 hosts.
   - The code (src/hu2026_checks.py wasp_hosts, as of commit 898b81a) attached the facility by host
     name. For HS19 Table 1 rows, the name column holds HS19's SimbadName, but the facility table is keyed
     by the archive's host name. A host whose SimbadName is a catalogue designation therefore got no
     label, even though its hot Jupiter is a WASP discovery. The name-based variant (D1) had the same
     fault.
   - Nine hosts in the 297 were affected. Matched on the Gaia DR2 source_id instead, they are:

     | Archive name | HS19 SimbadName | disc_facility | disc_year |
     |---|---|---|---|
     | WASP-70 A | TYC 5782-970-1 | SuperWASP | 2014 |
     | WASP-147 | TYC 6411-312-1 | SuperWASP-South | 2018 |
     | WASP-151 | EPIC 246441449 | SuperWASP-South | 2017 |
     | WASP-156 | TYC 38-617-1 | SuperWASP | 2017 |
     | WASP-158 | TYC 5264-1048-1 | SuperWASP-South | 2018 |
     | WASP-161 | TYC 5435-1109-1 | SuperWASP-South | 2018 |
     | WASP-168 | TYC 8103-143-1 | SuperWASP-South | 2018 |
     | WASP-172 | 2MASS J13174412-4714152 | SuperWASP-South | 2018 |
     | WASP-173 A | TYC 7518-468-1 | SuperWASP-South | 2018 |

   - For all nine, the HS19 Table 1 source_id equals the archive's gaia_dr2_id. No host leaves the sample,
     and no existing label changes.
   - The fault was found on 2026-11-09, while documenting the pipeline's choices. That was after the
     frozen analysis had been run.

3. The only change: the membership join, plus the items in sections 4-8.
   - **Join.** WASP membership is assigned by matching the host's Gaia DR2 source_id to the archive's
     gaia_dr2_id (code: wasp_hosts(cfg, join="source_id")).
   - **Planets considered (Q1).** The facility is taken from the host's planets in the archive's
     hot-Jupiter selection: pscomppars snapshot 2026-10-28, P < 10 d, pl_bmassj > 0.1 MJup with a measured
     mass provenance (upper limits kept), **and disc_year ≤ 2019**. Facilities come from the 2026-11-04
     disc_facility query.
     - The frozen run used this selection, but the frozen text did not state it. It is stated here.
     - The year limit excludes **none** of the 107 hosts. The count is 107 with the year limit, without
       it, or when every planet of the host is considered.
   - **Name-based variant D1 (Q4).** The name test uses HS19's ArchiveName ("WASP-" prefix), not the
     SimbadName: **109 hosts** (107 plus WASP-53 and WASP-81, whose facility is "Multiple Facilities").
   - The facility test and everything else in sections A-E of the frozen text are unchanged. Corrected
     counts:

     | D1: plus a name starting "WASP-" (HS19 ArchiveName) | 100 | **109** |

     (notes/wasp_amendment1_power.md; data/processed/hu2026/power_amendment1.json).
   - Method as E4: field velocities only, HS19-style z + colour matching, 10,000 control samples; two-sided
